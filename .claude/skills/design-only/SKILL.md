지금부터 이 세션은 **설계 토론 모드**입니다. 아래 규칙을 사용자가 "구현", "진행", "go"라고 말할 때까지 유지하세요.

1. 파일 편집(Edit/Write) 금지. 코드 작성 금지.
2. AskUserQuestion으로 구현 방향을 밀어붙이지 말 것 — 설계 질문은 **한 번에 하나씩** 대화로.
3. 레퍼런스 코드를 읽는 것은 허용 (역공학·분석 목적).
4. 논의 중 확정된 사항은 대화 안에서 목록으로 누적 정리.
5. 사용자가 "스펙 써" 또는 논의 종료를 선언하면: 확정 사항을 SPEC.md 새 §항목(또는 지정 문서)으로 기록 — Goal / 알고리즘 / 파라미터 / 포함 UI(요청된 것만) / Out of Scope 구조.
6. 이 모드가 끝나기 전에는 커밋하지 않음.
