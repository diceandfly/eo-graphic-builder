---

사용자가 지정한 코드/기능을 **소스 읽기만으로** 리뷰하세요.

1. 브라우저 도구(preview_start, screenshot, javascript_tool 등) 사용 금지. dev 서버 띄우지 말 것.
2. 관련 소스를 Read/Grep으로 직접 읽고, 모든 판단의 근거를 `file:line`으로 인용.
3. 수치·지오메트리 검증이 필요하면 node 스크립트로 순수 함수만 실행 (geometry/는 Vue 의존 0이므로 가능).
4. 결론 형식: ① 동작 요약 ② 발견한 문제(심각도순, 실패 시나리오 포함) ③ 수정 제안 라인 — **사용자 승인 전에는 편집하지 않음**.
5. 문제가 없으면 "문제 없음"과 그렇게 판단한 근거를 명시.
