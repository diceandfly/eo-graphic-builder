## 2. 시작하기

EO Graphic Builder는 나사축 단면 모티프를 만드는 그래픽 툴입니다. 슬라이더 몇 개로 유닛(나사축)의 형태를 잡고, 프레임 안에 배치·정렬해 그래픽을 완성한 뒤 SVG나 PNG로 내보낼 수 있습니다.

- **접속**: https://diceandfly.github.io/eo-graphic-builder/
- **권장 브라우저**: Chrome
- **저장은 어떻게 되나요?** 작업은 지금 쓰고 있는 브라우저에 자동으로 저장됩니다. 단, 컴퓨터나 브라우저를 바꾸면 이어서 볼 수 없으니, 다른 사람에게 넘기거나 백업하려면 [저장 버튼으로 파일을 내려받아](#15-저장열기내보내기) 전달하세요.

## 3. 화면 구성

| 위치 | 이름 | 역할 |
|---|---|---|
| 좌측 | **메인 패널** | 선택한 대상에 따라 내용이 바뀝니다 — 아무것도 선택 안 함: 프리셋 목록 / 유닛 선택: 형태 조절 / 프레임 선택: 프레임 설정 |
| 좌상단 | **파일 바** | 도움말 · 저장 · 열기 · 초기화 |
| 우상단 | **매니저 바** | 추후 추가될 기능의 자리입니다 |
| 좌하단 | **정렬 바** | 정렬 · 등간격 배치 |
| 하단 중앙 | **컬러 바 + 도구 바** | 브랜드 컬러 7색 + 커스텀 / 선택·프레임·스포이드·블렌드·배열 도구 |
| 우하단 | **코너 바 (보기)** | 배경 격자 · 선택 박스 · 그리드 표시 · 확대 배율 |

**버튼은 좌클릭 = 실행, 우클릭 = 세부 옵션**이 공통 규칙입니다. 슬라이더 옆 숫자는 직접 입력할 수도 있습니다.

## 5. 오브젝트 선택·이동·변형

### 선택
- **클릭** = 하나 선택, **빈 곳에서 드래그** = 영역 안의 여러 개를 한 번에 선택
- 그룹에 속한 것을 클릭하면 그룹 전체가 선택됩니다
- 여러 개를 선택한 상태에서 **그중 하나를 다시 클릭**하면 그 오브젝트가 [정렬의 기준](#11-정렬과-배열)이 됩니다 (두꺼운 테두리로 표시)

### 이동
- 드래그로 이동합니다
- **방향키** = 조금씩 이동, **Shift+방향키** = 10배씩 (이동 폭은 [보기 옵션](#13-보기-옵션-코너-바)에서 조절)
- **Shift+드래그** = 수평·수직으로만 이동

### 크기·회전 (선택 박스의 핸들)
- 모서리·변 핸들 드래그 = 크기 조절 (**Shift** = 비율 유지, **Alt** = 중심 고정)
- 회전 핸들 = 90°씩 회전
- 선택 박스 버튼: 좌우/상하 뒤집기 · 복제 · 삭제
- **Q / W** = 겹친 순서를 맨 앞 / 맨 뒤로

### 복사·붙여넣기
- **Alt+드래그** = 끌면서 복사
- **⌘C** = 복사 — 앱 안에서 붙여넣을 수 있고, 동시에 피그마 등 다른 툴에 바로 붙여넣을 수 있는 SVG로도 복사됩니다
- **⌘⇧C** = 이미지(PNG, 2배 해상도)로 복사
- **⌘V** = 마우스 위치에 붙여넣기 — 여러 개를 복사했다면 배치 그대로, 그룹은 그룹 그대로 붙습니다
- **⇧D** = 마지막에 한 작업(블렌드·배열 등)을 한 번 더 실행

### 우클릭 메뉴
삭제 · 좌우/상하 뒤집기 · [프리셋 등록](#14-유닛-프리셋) · [SVG/PNG 복사 · 파일 내보내기](#15-저장열기내보내기)

### 되돌리기
- **⌘Z / ⌘⇧Z** — 캔버스에서 한 작업과 프리셋 등록·삭제를 되돌릴 수 있습니다. 보기 설정·도구 옵션은 되돌리기 대상이 아닙니다.

## 6. 유닛 파라미터 (메인 패널)

유닛을 선택하면 왼쪽 패널에서 형태를 조절할 수 있습니다. 패널 맨 위의 이름을 클릭하면 이름을 바꿀 수 있습니다.

### SIZE — 크기
- 가로/세로 값과 비율 버튼(12:5 ~ 9:16)
- 여러 개를 선택했을 때는 전체를 하나의 덩어리로 크기 조절합니다. 각각 따로 조절하고 싶으면 오른쪽 위 **each**를 켜세요

### GRID — 스레드 배치
- **cols** — 스레드(빗살) 개수
- **pitch compression** — 빗살 폭을 한쪽으로 갈수록 점점 좁아지게 만듭니다. 0이 균등, +/−는 좁아지는 방향입니다. 슬라이더 아래 비율 버튼(1:1 ~ 1+√2)으로 자주 쓰는 값을 바로 지정할 수 있고, 방향을 바꿔도 빗살의 기울기 모양은 유지됩니다
- **gutter mode** — 빗살 사이 간격을 고정값(fixed)으로 할지, 폭에 비례(prop)하게 할지

### SHAPE — 형태
- **shaft size** — 가운데 축의 두께 (유닛 높이 대비 %)
- **thread top / bottom width** — 빗살 윗변/아랫변의 폭 (기울기가 달라집니다)
- **thread sides** — double: 축 위아래로 빗살 / single: 위쪽에만

## 7. 컬러

- **컬러 바**: 브랜드 7색 — EO NEON(1) · WORLD GREEN(2) · HORIZON BLUE(3) · HALO WHITE(4) · STEEL GREY(5) · VOID GREY(6) · SPACE BLACK(7). 숫자 키로도 바로 적용됩니다
- **커스텀 컬러(C)**: 클릭하면 적용, **우클릭**하면 원하는 색을 고르는 픽커가 열립니다
- 선택한 오브젝트가 있으면 그 오브젝트의 색이 바뀌고, 없으면 "다음에 만들 오브젝트의 색"으로 기억됩니다
- **최근 사용한 색**: 직접 고른 색은 자동으로 최대 6개까지 기억되어, 커스텀 픽커·[프레임 테두리 픽커](#9-프레임)·[퀵 프레임 픽커](#8-도구-바) 어디서든 다시 쓸 수 있습니다. 지우려면 색 칩을 우클릭하세요
- 픽커에는 색상 코드(#RRGGBB)를 직접 입력할 수도 있습니다

## 8. 도구 바

| 도구 | 좌클릭 / 단축키 | 우클릭 |
|---|---|---|
| **Select** | 유닛 선택 모드 (V) | [프레임 선택 모드](#9-프레임)로 전환 (A) |
| **Frame** | [프레임](#9-프레임) 그리기 (F) — 드래그한 크기로 만들어집니다. 버튼을 **더블클릭**하면 미리 정해둔 크기로 즉시 생성 | 퀵 프레임 설정: 크기·여백·간격·색 |
| **Eyedropper** | 스포이드 (I) | 무엇을 가져올지 선택: 색 / 크기 / 그리드 / 형태·스타일 / 방향 |
| **Blend** | 블렌드 실행 (B) | 방향 · 반복 수 · 간격 · 크기 변화 |
| **Grid arrange** | 배열 실행 | 방향(격자·가로만·세로만) · 간격 · 열 수 |

### 스포이드 — 다른 오브젝트의 속성 가져오기
오브젝트를 선택해 두고 스포이드로 다른 오브젝트를 클릭하면, 우클릭에서 켜둔 항목(색·크기·그리드·형태 등)을 그대로 가져옵니다. 유닛은 유닛에게서, 프레임은 프레임에게서만 가져올 수 있습니다 — 겹쳐 있어도 다른 종류는 클릭되지 않으니 안심하고 찍으세요.

### 블렌드 — 반복 복제
유닛(또는 그룹)을 선택하고 실행하면, 정한 방향으로 점점 커지거나 작아지는 복사본들이 일정 간격으로 만들어지고 자동으로 그룹이 됩니다.

### 그리드 배열 — 정리 배치
선택한 오브젝트들을 격자 형태로 가지런히 재배치합니다(그룹은 한 덩어리로). 옵션에서 **가로만 / 세로만** 정리할 수도 있습니다.

## 9. 프레임

프레임은 유닛을 담아 배치하는 판입니다. 아트보드처럼 쓰면 됩니다.

### 만들기
- **F**를 누르고 드래그, 또는 프레임 버튼 **더블클릭**(미리 설정한 크기·색으로 즉시 생성)

### 프레임 선택 모드 (A ↔ V)
- **A** 키 또는 선택 도구 우클릭으로 전환합니다. 이 모드에서는 프레임만 잡히고 유닛은 클릭해도 지나갑니다 — 유닛이 가득한 프레임도 편하게 옮길 수 있습니다. **V**로 돌아옵니다

### 내용물은 어떻게 따라오나요?
- 유닛의 중심이 프레임 안에 있으면 그 프레임의 내용물로 취급됩니다 (겹쳐 있으면 위에 있는 프레임)
- 프레임을 **이동·정렬·배열**하면 내용물이 함께 움직이고, **크기 조절**은 프레임만 바뀝니다
- 프레임을 **복사·붙여넣기·내보내기**하면 내용물이 포함됩니다
- 가장 최근에 만들었거나 만진 프레임에는 옅은 테두리가 표시됩니다 — [단독 정렬의 기준](#11-정렬과-배열)이 되는 프레임입니다

### 프레임 설정 (메인 패널)
- **SIZE** — px/cm 표기를 바꿀 수 있습니다. cm 모드에서는 인쇄용 규격 버튼(A2~A5·Letter)과 dpi 설정이 나타납니다
- **STYLE** — 채움(fill)과 테두리(stroke)를 각각 켜고 끌 수 있습니다. 테두리는 두께·색 조절 가능
- **GRID** — 프레임 안에 여백(margin)·간격(gutter)·행/열을 가진 레이아웃 격자를 표시합니다. **compression**을 켜면 격자의 행/열 폭을 한쪽으로(→) 또는 가운데 기준(↔)으로 점점 좁아지게 만들 수 있습니다. 이 격자는 화면 가이드일 뿐 내보내기에는 포함되지 않으며, 오브젝트를 끌면 [격자 선에 자석처럼 붙습니다](#12-스마트-가이드스냅)

## 10. 그룹과 링크

### 그룹 (⌘G / ⌘⇧G) — 묶어서 다루기
- 여러 오브젝트를 묶으면 클릭·이동·정렬에서 한 덩어리로 움직입니다. 그룹 안에 그룹을 또 만들 수도 있습니다
- 그룹을 선택하면 패널 위에서 그룹 이름을 바꿀 수 있습니다

### 링크 — 형태 함께 바꾸기
- 유닛 2개 이상을 선택하고 패널의 **LINK** 섹션에서 link parameters를 누르면, 이후 한쪽의 형태를 바꿀 때 링크된 유닛들이 함께 바뀝니다
- 어떤 항목을 함께 바꿀지는 칩(size·grid·shape·color·orientation)으로 고릅니다
- 링크된 유닛에는 사슬 아이콘이 표시됩니다
- **복사한 유닛은 원본과 같은 링크에 들어갑니다.** 복사본들만 따로 묶고 싶다면: 복사본들만 선택한 뒤 칩 하나를 눌러보세요 — 그 순간 선택한 것들끼리 새 링크로 분리됩니다. unlink parameters 버튼은 선택한 것들만 링크에서 빼냅니다

## 11. 정렬과 배열

좌하단 정렬 바:

- **정렬 6종**: 왼쪽/가운데/오른쪽 · 위/가운데/아래 맞춤 — 기준은 [다시 클릭으로 지정한 오브젝트](#5-오브젝트-선택이동변형), 지정이 없으면 선택 전체의 테두리
- **등간격 2종**: 양 끝은 그대로 두고 사이 간격을 똑같이 맞춥니다
- **프레임에 맞춰 정렬**: 유닛 하나만 선택해도, [활성 프레임](#9-프레임)(또는 그 유닛이 담긴 프레임)이 있으면 그 프레임을 기준으로 정렬됩니다 — 프레임 정가운데 배치가 클릭 두 번입니다

## 12. 스마트 가이드·스냅

오브젝트를 끌면 자동으로 도와줍니다:

- 다른 오브젝트의 **가장자리·중심**에 가까워지면 자석처럼 붙고 안내선이 표시됩니다

- **간격 맞추기**: 이웃한 오브젝트들과 같은 간격이 되는 위치, 두 오브젝트의 정가운데도 잡아줍니다
- **배경 격자에 붙이기**: 코너 바 → 격자 버튼 우클릭 → Snap to grid를 켜면 배경 격자 단위로 움직입니다

## 14. 유닛 프리셋

자주 쓰는 유닛 형태를 저장해 두고 꺼내 쓰는 기능입니다.

- **등록**: 유닛 우클릭 → Register unit preset
- **꺼내 쓰기**: 아무것도 선택하지 않으면 왼쪽 패널에 프리셋 목록이 보입니다. 클릭하면 화면 가운데에 만들어집니다 (썸네일/리스트 보기 전환 가능)
- **삭제**: ×를 3초 안에 두 번 클릭해야 지워집니다 (실수 방지). 기본 유닛은 지워지지 않습니다
- **공유**: EXPORT/IMPORT JSON 버튼으로 프리셋 모음을 파일로 주고받을 수 있습니다
- 등록·삭제도 ⌘Z로 되돌릴 수 있습니다

## 15. 저장·열기·내보내기

### 자동 저장
따로 저장하지 않아도 작업은 브라우저에 계속 저장됩니다. 새로고침해도 마지막 상태가 그대로 열립니다.

### 파일로 저장·열기 (파일 바)
- **저장** = 작업 전체를 파일(JSON)로 내려받기, **열기** = 그 파일 불러오기 (보고 있던 화면 위치까지 복원됩니다)
- 각 버튼을 **우클릭**하면 무엇을 저장/불러올지 고를 수 있습니다: **Work data**(작업물) / **Tools setting**(도구·컬러 설정) / **Viewport setting**(화면·격자 설정) — 예: 내 설정만 동료에게 전달하기
- 다른 사람과 작업을 주고받을 때는 이 파일을 사용하세요

### 내보내기
- **⇧E** 또는 우클릭 메뉴 = 선택한 것을 SVG 파일로 저장 — 여러 개를 선택하면 배치 그대로 한 파일이 되고, [프레임](#9-프레임)은 내용물까지 포함됩니다
- **⌘C** = SVG로 복사해서 피그마 등에 바로 붙여넣기, **⌘⇧C** = 이미지(PNG, 2배 해상도)로 복사
- 화면의 가이드 선(유닛/프레임 그리드)은 내보낸 파일에 포함되지 않습니다

### 초기화 (파일 바의 리셋 버튼)
모든 작업을 지우고 처음 상태로 돌아갑니다. 실수 방지를 위해 세 번 눌러야 실행되며, 실행 후에도 ⌘Z로 되돌릴 수 있습니다.
