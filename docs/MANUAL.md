## 2. 시작하기

파라메트릭 나사축 단면 그래픽 빌더입니다. 유닛(나사축)의 형태를 파라미터로 조형하고, 프레임 안에 배치·정렬해 브랜드 그래픽을 만든 뒤 SVG/PNG로 내보냅니다.

- **접속**: https://diceandfly.github.io/eo-graphic-builder/
- **권장 브라우저**: Chrome (크로미움 계열)
- **저장 방식**: 작업은 이 브라우저에 자동 저장됩니다(기기별·브라우저별). 다른 사람/기기와 공유하려면 [저장(JSON 파일) → 열기](#15-저장열기내보내기)를 사용하세요. 브라우저당 자동 저장 문서는 1개입니다.

## 3. 화면 구성

| 위치 | 이름 | 역할 |
|---|---|---|
| 좌측 | **메인 패널** | 선택 상태에 따라 내용이 바뀝니다 — 선택 없음: 유닛 프리셋 브라우저 / 유닛·그룹 선택: 파라미터 편집 / 프레임 선택: 프레임 속성 |
| 좌상단 | **파일 바** | 도움말 · 저장 · 열기 · 초기화 |
| 우상단 | **매니저 바** | 레이어/패턴 매니저 자리 (추후 기능) |
| 좌하단 | **정렬 바** | 정렬 6종 + 등간격 2종 |
| 하단 중앙 | **컬러 바 + 도구 바** | 브랜드 스와치 7색 + 커스텀 / 선택·프레임·스포이드·블렌드·배열 도구 |
| 우하단 | **코너 바 (보기)** | 캔버스 그리드 · 바운딩박스 · 유닛/프레임 그리드 · 줌 |
| 우하단 위 | **리소스 모니터** | OBJ/MEM/FPS (도움말 버튼 우클릭으로 토글) |

각 바의 버튼은 **좌클릭 = 실행, 우클릭 = 옵션 팝업**이 기본 문법입니다. 팝업은 다른 팝업을 열면 자동으로 닫히고, 5초간 조작이 없으면 스스로 닫힙니다.

### 입력 필드 공통 문법

- **Enter** = 즉시 커밋(+필드 플래시 피드백), **바깥 클릭** = 커밋
- 숫자 필드의 **▲▼ 화살표** = 항목별 지정 단위로 증감
- 슬라이더 값 표시부도 직접 입력 가능하며, 단위(%·x 등)는 필드 안에 표시되지만 편집 대상이 아닙니다

## 4. 캔버스 기본 조작

| 동작 | 방법 |
|---|---|
| 팬(화면 이동) | **Space + 드래그**, 또는 트랙패드 두 손가락 스크롤 |

## 5. 오브젝트 선택·이동·변형

### 선택
- **클릭** = 단일 선택, **빈 곳 드래그** = 마퀴(범위) 선택, **빈 곳 클릭** = 선택 해제
- 그룹 멤버를 클릭하면 그룹 전체가 선택됩니다
- 다중 선택 상태에서 **선택된 오브젝트를 다시 클릭** = **키 오브젝트** 지정 ([정렬](#11-정렬과-배열) 기준, 두꺼운 하이라이트)

### 이동
- 드래그 (클릭 오인 방지를 위해 6px 이상 움직여야 이동 시작)
- **방향키** = 넛지 이동(기본 5px, [보기 옵션](#13-보기-옵션-코너-바)에서 변경), **Shift+방향키** = 10배
- **Shift+드래그** = 수직/수평 축 고정

### 변형 (선택 오버레이 핸들)
- 모서리/변 핸들 드래그 = 리사이즈 (**Shift** = 비율 고정, **Alt** = 중심 대칭)
- 회전 핸들 = 90° 단위 회전
- 오버레이 버튼: 좌우/상하 반전 · 복제 · 삭제
- **Q / W** = 맨 앞으로 / 맨 뒤로 (z-오더)

### 복제·클립보드
- **Alt+드래그** = 드래그 복제 (그룹 구조 유지)
- **⌘C** = 복사 — 앱 내부 클립보드(다중 선택 지원) + 시스템 클립보드에 SVG 텍스트(피그마 등에 바로 붙여넣기)
- **⌘⇧C** = 시스템 클립보드에 PNG(2배율)
- **⌘V** = 붙여넣기 (마우스 위치 중심, 다중이면 상대 배치 유지, 그룹은 새 그룹으로 재생성)
- **⇧D** = 마지막 액션 반복 (블렌드/배열 등)

### 컨텍스트 메뉴 (오브젝트 우클릭)
Delete · Flip horizontal/vertical · [Register unit preset](#14-유닛-프리셋) · [Copy as SVG/PNG · Export SVG file](#15-저장열기내보내기)

### 실행 취소
- **⌘Z / ⌘⇧Z** = undo/redo — 캔버스 작업과 프리셋 등록/삭제가 대상입니다. 뷰·도구 설정은 히스토리에 포함되지 않습니다.

## 6. 유닛 파라미터 (메인 패널)

유닛(나사축)을 선택하면 표시됩니다. 패널 상단의 이름을 클릭하면 이름을 바꿀 수 있습니다.

### SIZE
- **width / height** + 비율 칩(12:5 ~ 9:16)
- 다중 선택 시 기본은 통합 바운딩박스 기준이며, 헤더의 **each** 토글을 켜면 각 유닛에 개별 적용됩니다

### GRID
- **cols** — 스레드 컬럼 수
- **pitch compression** — 컬럼 폭의 등비 압축 (±2.5x, 0 = 균등, 부호 = 진행 방향). 슬라이더 아래 **비율 칩**(1:1 ~ 1+√2)으로 프리셋 지정. 부호를 바꿔도 스레드의 기울기(쉐입)는 유지됩니다
- **gutter mode** — fixed(px 고정) / prop(컬럼 폭 비례) + gutter 값

### SHAPE
- **shaft size** — 축 두께 (UNIT HEIGHT × N%)
- **thread top / bottom width** — 스레드 사다리꼴의 상/하변 폭
- **thread sides** — double(상하 대칭) / single(상단만, 축이 바닥에 접함)

## 7. 컬러

- **컬러 바**: 브랜드 7색 — EO NEON(1) · WORLD GREEN(2) · HORIZON BLUE(3) · HALO WHITE(4) · STEEL GREY(5) · VOID GREY(6) · SPACE BLACK(7)
- **커스텀 컬러(C)**: 좌클릭/C키 = 적용, **우클릭** = 픽커 팝업
- 선택이 있으면 즉시 적용, 없으면 "현재 컬러"로 지정되어 이후 생성되는 오브젝트에 쓰입니다
- **최근 컬러 슬롯**: 오브젝트에 실제 적용한 비 브랜드 컬러가 자동 저장(최대 6)되며, 커스텀 픽커·[프레임 스트로크 픽커](#9-프레임)·[퀵프레임 픽커](#8-도구-바)가 **같은 슬롯을 공유**합니다. 칩 우클릭 = 삭제
- 픽커 공통: 색을 픽하면 자동 적용 후 닫힘, hex 입력은 Enter 커밋, 빈 hex = 기본값 복귀

## 8. 도구 바

| 도구 | 좌클릭 / 단축키 | 우클릭 |
|---|---|---|
| **Select** | 유닛 선택 모드 (V) | **[프레임 셀렉 모드](#9-프레임) 전환** (A) |
| **Frame** | [프레임](#9-프레임) 그리기 모드 (F) — 드래그한 크기로 생성. **버튼 더블클릭** = 퀵 프레임 즉시 생성 | 퀵 프레임 설정: width·height·margin·gutter·color |
| **Eyedropper** | 스포이드 모드 (I) | 흡수 범주: Color / Size / Grid / Shape·Style / Orientation |
| **Blend** | 블렌드 실행 (B) | 옵션: direction h·v / repeat / gap / scale |
| **Grid arrange** | 배열 실행 | 옵션: axis(grid·x·y) / gap / columns |

### 스포이드
선택된 오브젝트가 있는 상태에서 다른 오브젝트를 클릭하면, 켜둔 범주의 속성을 흡수합니다. **같은 타입끼리만** 동작합니다(유닛→유닛, 프레임→프레임 — 겹쳐 있어도 다른 타입은 클릭되지 않습니다). 프레임의 경우 Grid = 레이아웃 그리드·컴프레션 일체, Shape/Style = fill/stroke 설정입니다.

### 블렌드
단일 유닛 또는 [단일 그룹](#10-그룹과-링크)(전체 선택)에서 실행 — 진행 축 방향으로 등비 스케일 사본을 gap 간격으로 생성하고 그룹으로 묶습니다. 프레임과 혼합 선택에는 동작하지 않습니다.

### 그리드 배열
2개 이상의 블록(그룹은 한 덩어리)을 읽기 순서대로 그리드에 재배치합니다. **axis x/y** 모드는 해당 축으로만 gap 간격 재배치(교차축 위치 유지). [프레임](#9-프레임)을 배열하면 내용물이 함께 이동합니다.

## 9. 프레임

프레임은 레이아웃 컨테이너입니다. 유닛과 별개의 선택 레이어에서 동작합니다.

### 만들기
- **F** → 드래그, 또는 프레임 버튼 **더블클릭**(퀵 프레임 — 설정된 크기·그리드·색)

### 프레임 셀렉 모드 (A ↔ V)
- 선택 도구 우클릭 또는 **A** 키로 진입 (해제는 **V**)
- 이 모드에서는 프레임만 선택·조작되고 유닛은 통과됩니다. [스마트 스냅](#12-스마트-가이드스냅)도 프레임끼리만 동작합니다

### 소유권 (내용물)
- 유닛/그룹 블록의 **중심점이 들어있는 프레임**(겹치면 위쪽 프레임)이 그 블록을 소유합니다 — 영속 관계가 아니라 이동 시점마다 판정됩니다
- 프레임 **이동/방향키/배열/정렬** 시 소유 유닛이 함께 이동, **리사이즈**는 프레임만
- 프레임 **복제/붙여넣기** 시 내용물 포함, **[export](#15-저장열기내보내기)** 시 내용물 포함
- 가장 최근 만들었거나 조작한 프레임에는 은은한 **활성 아웃라인**이 표시됩니다

### 프레임 속성 (메인 패널)
- **SIZE** — px/cm 표기 전환. cm 모드에서는 dpi 기준 환산 + 출판 규격 칩(A2·A3·A4·A5·Letter)
- **STYLE** — fill on/off, stroke on/off(+두께·색, 색은 [최근 컬러 공유 픽커](#7-컬러))
- **GRID** — margin · gutter rows/cols · rows · cols · **compression**(on/off, 축별 dir(→)/sym(↔) 모드, ±9x 슬라이더 + 비율 칩, rows-cols 잠금). 그리드는 가이드 전용으로 export에는 포함되지 않으며, 오브젝트 [스냅](#12-스마트-가이드스냅) 기준선으로 동작합니다

## 10. 그룹과 링크

### 그룹 (⌘G / ⌘⇧G)
- 여러 오브젝트를 한 덩어리로 — 클릭·이동·[정렬·배열](#11-정렬과-배열)에서 1블록으로 취급됩니다. 그룹 위에 그룹(중첩)도 가능합니다
- 그룹 선택 시 패널 상단에서 그룹 이름을 바꿀 수 있습니다

### 링크 (파라미터 동기화)
- 2개 이상 유닛 선택 → 패널 **LINK 섹션** → link parameters. 링크된 유닛들은 [파라미터](#6-유닛-파라미터-메인-패널) 편집이 서로 동기화됩니다
- **스코프 칩**(size·grid·shape·color·orientation)으로 동기화 범주를 선택합니다
- 링크된 유닛에는 우상단에 사슬 배지가 표시됩니다 ([보기 옵션](#13-보기-옵션-코너-바)에서 숨김 가능)
- **복사/복제된 유닛은 원본 링크그룹에 합류**합니다. 사본들만 따로 관리하려면: 사본들만 선택 → 스코프 칩을 하나 조작 → **선택분이 새 링크그룹으로 분리**됩니다. 버튼(unlink parameters)은 선택분만 링크에서 빼냅니다
- 멤버가 1개만 남은 링크그룹은 자동 해체됩니다

## 11. 정렬과 배열

좌하단 정렬 바 — 2개 이상 블록 선택 시 활성:

- **정렬 6종**: 좌/중/우 · 상/중/하 — 기준은 **키 오브젝트**([선택 중 재클릭](#5-오브젝트-선택이동변형)), 없으면 선택 전체 bbox
- **등간격 2종**: 3개 이상 블록에서 양 끝 고정, 사이 간격 균등
- **프레임 기준 정렬**: 단일 유닛/그룹만 선택해도, [활성 프레임](#9-프레임)(또는 그 유닛이 속한 프레임)이 있으면 그 프레임 bbox를 기준으로 정렬됩니다
- 프레임을 정렬/등간격하면 내용물이 함께 이동합니다

## 12. 스마트 가이드·스냅

이동/리사이즈 중 자동 동작:

- 다른 오브젝트의 **엣지·센터**(화면 6px 반경) 스냅 + 가이드 라인
- **[프레임 레이아웃 그리드](#9-프레임) 라인**(마진·컬럼·거터 경계)에도 스냅 — 프레임이 화면에서 충분히 클 때만
- **등간격 스냅**: 이웃 간격 복제·두 오브젝트 사이 중앙 배치
- **캔버스 그리드 스냅**: 코너 바 → Canvas grid setting → Snap to grid
- 화면에 보이는 오브젝트만 스냅 후보가 되며, 화면상 아주 작은 오브젝트는 중심점만 후보가 됩니다
- 프레임 셀렉 모드에서는 프레임끼리만 스냅됩니다

## 13. 보기 옵션 (코너 바)

| 버튼 | 좌클릭 | 우클릭 |
|---|---|---|
| 캔버스 그리드 | 격자 표시 토글 | Canvas/Grid color(무채색) · Grid size · Snap · reset |
| 바운딩박스 | 선택 오버레이 표시 토글 | Arrow nudge(방향키 px) · 그룹 아웃라인 · 링크 배지 표시 |
| 유닛/프레임 그리드 | **양쪽 그리드 마스터 토글 (G)** | Unit min · Thread min · Unit/frame grid color · **Unit grid / Frame grid 개별 토글** · reset |
| % 배지 | 줌 100% | **Auto seam stroke** 토글 · Off above zoom(컷오프 %) |

- **Unit min** — 유닛 최소 크기(px), **Thread min** — 어떤 상황에서도 이보다 얇게 렌더되는 스레드를 보정하는 문서 px 절대 하한 (export와 1:1)
- **Auto seam stroke** — 줌아웃 시 도형 접합부의 헤어라인을 봉합하는 보정(축에만 적용, 줌에 비례해 얇아짐)
- **리소스 모니터** — 도움말(?) 버튼 우클릭 → Resource monitor: OBJ(오브젝트 수)/MEM/FPS, 임계 초과 시 붉게 표시

이 설정들은 브라우저에 저장되어 다음 세션에도 유지됩니다.

## 14. 유닛 프리셋

- **등록**: 유닛 우클릭 → Register unit preset
- **브라우저**: 선택이 없을 때 메인 패널에 표시 — thumbs/list 보기, 클릭 = 캔버스 중앙에 배치
- **삭제**: ×를 3초 안에 두 번 클릭 (실수 방지). Default Unit은 삭제되지 않습니다
- **공유**: EXPORT/IMPORT JSON — 프리셋 라이브러리를 파일로 내보내고 합칠 수 있습니다
- 프리셋 등록/삭제도 ⌘Z 대상입니다

## 15. 저장·열기·내보내기

### 자동 저장
작업 문서·설정은 브라우저에 자동 저장됩니다. 새로고침하면 마지막 상태가 복원됩니다.

### 프로젝트 저장/열기 (파일 바)
- **저장** = JSON 파일 다운로드, **열기** = JSON 파일 로드 (카메라 위치 포함)
- 각 버튼 **우클릭** = 범위 선택: **Work data**(오브젝트·그룹·링크) / **Tools setting**(도구·컬러 설정) / **Viewport setting**(그리드·렌더 옵션) — 예: 설정만 공유하거나, 작업만 받아오기
- 팀 공유는 이 JSON 파일로 합니다

### 내보내기
- **⇧E** 또는 컨텍스트 메뉴 = 선택을 SVG 파일로 (다중 선택 = 상대 배치 유지 컴포지트, [프레임](#9-프레임) = 내용물 포함)
- **⌘C** = SVG 텍스트 복사 (피그마 등에 바로 붙여넣기), **⌘⇧C** = PNG(2x) 복사
- 유닛 그리드/프레임 그리드 가이드는 export에 포함되지 않습니다

### 초기화 (파일 바 리셋 버튼)
3단계 확인(마지막은 묘비 아이콘)을 거쳐 대시보드를 초기화합니다. ⌘Z로 복구 가능합니다.
